# Contributing to Rural Hospital Digital System

## Prerequisites

- Java 17
- Maven
- Git
- GitHub Account

## Installation

1. Fork the repository
2. Clone your fork

```bash
git clone https://github.com/yourusername/rural-hospital-digital-system.git
```

3. Open in IntelliJ IDEA
4. Run:

```bash
mvn clean install
```

## Coding Standards

- Follow Java naming conventions
- Write JUnit tests
- Ensure CI/CD pipeline passes

## How to Contribute

1. Fork repository
2. Choose an issue labeled:
   - good-first-issue
   - feature-request
3. Create a branch
4. Commit changes
5. Submit Pull Request

## Pull Request Guidelines

- Include clear description
- Link issue number
- Ensure tests pass
